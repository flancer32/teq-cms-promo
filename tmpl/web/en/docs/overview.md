# Understand the model, then try it

TeqCMS publishes version-controlled Markdown for agents and renders localized HTML for people. I keep the content, translations, and presentation in files; the CMS supplies the publication pipeline.

## Start here

- [Installation](/en/docs/install): run this real example and edit a source.
- [Configuration](/en/docs/config): configure site publication and select locales.
- [Locales](/en/docs/locales): understand exact-language HTML and neutral Markdown.
- [Localization](/en/docs/translate): maintain and review language variants.
- [CLI](/en/docs/cli): serve the site and generate discovery files.

## Work on your site

- [Working with agents](/en/docs/dev-llm): give tasks and review file changes.
- [ADSM](/en/docs/adsm): organize the project's textual instructions.
- [Integration](/en/docs/plugins): understand the host and package boundaries.
- [Troubleshooting](/en/docs/troubleshooting) and [FAQ](/en/docs/faq): resolve common questions.

The [engine's publication guide](https://github.com/flancer32/teq-cms/blob/main/docs/publications.md) is the detailed runtime reference. For help applying it to your project, [contact me](/en/contacts).
