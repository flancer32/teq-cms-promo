Configuration

The CLI host loads environment settings. Use TEQFW_TMPL__ALLOWED_LOCALES and TEQFW_TMPL__DEFAULT_LOCALE for locales. Set TEQ_CMS__BASE_URL and explicitly configure TEQ_CMS__PUBLICATION_FAMILIES to publish Markdown-backed pages. TEQ_CMS__PUBLICATION_MACHINE_LOCALES selects public Markdown locales.

The optional agent contact inbox is enabled with TEQ_CMS__AGENT_MESSAGE_ENABLED=true.
