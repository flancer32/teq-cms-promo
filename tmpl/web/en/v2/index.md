# TeqCMS: build a site from files

I built TeqCMS for sites whose pages and translations are managed in Git. The CMS reads Markdown by locale and renders HTML through shared templates on the server. This site shows it in use.

<div class="section">

## What TeqCMS does

- Reads localized Markdown sources from project files.
- Selects a page for the requested locale and renders it on the server.
- Lets me keep content and its change history in Git.

</div>

<div class="section">

## How I work on this site

I describe a task in plain text, and an external AI agent edits the page files. I review the result and the change history. The agent is not built into TeqCMS: the CMS displays the prepared content.

</div>
