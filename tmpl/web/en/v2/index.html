TeqCMS: build a site from files

I built TeqCMS for sites whose pages and translations are managed in Git. The CMS finds templates by locale and renders HTML on the server. This site shows it in use.

What TeqCMS does

  • Reads page templates from project files.
  • Selects a page for the requested locale and renders it on the server.
  • Lets me keep content and its change history in Git.

How I work on this site

I describe a task in plain text, and an external AI agent edits the page files. I review the result and the change history. The agent is not built into TeqCMS: the CMS displays the prepared content.

ADSM as a way of working

Agent Driven Site Management organizes how a person and an agent work on a site. I demonstrate that approach here with TeqCMS. Learn about ADSM.
