# Follow development on GitHub

I track TeqCMS improvements in the engine repository. Open [current issues](https://github.com/flancer32/teq-cms/issues) for proposals and discussions, and [releases](https://github.com/flancer32/teq-cms/releases) for published changes.

Have a use case the CMS should support? [Open an issue](https://github.com/flancer32/teq-cms/issues/new) describing your goal and expected behavior, or [contact me](/en/contacts). Priorities depend on real project needs; I don't promise a fixed delivery schedule here.
