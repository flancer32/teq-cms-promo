# Контент как код

**TeqCMS** реализует принцип «контент как код» — все страницы, шаблоны и переводы хранятся в обычных файлах и управляются через git. Это упрощает разработку, локализацию и сопровождение сайта.

- 📁 HTML-страницы, шаблоны и стили — это обычные файлы в проекте
- 📝 Изменения редактируются в любимом редакторе, без CMS-интерфейса
- 🔀 История изменений фиксируется в git: можно сравнивать, откатывать, комментировать
- 🤝 Совместная работа с другими участниками происходит как при работе с кодом
- ⚙️ Структура проекта соответствует структуре URL, всё прозрачно и предсказуемо

Подход идеально подходит для лендингов, промо-сайтов, документации и других проектов, где важна простота, контроль и независимость от админок и баз данных.
