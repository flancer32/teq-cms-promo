# Развитие проекта — на GitHub

Я веду задачи TeqCMS в репозитории движка. В [открытых задачах](https://github.com/flancer32/teq-cms/issues) находятся предложения и обсуждения, в [релизах](https://github.com/flancer32/teq-cms/releases) — опубликованные изменения.

Нужна возможность для вашего проекта? [Создайте задачу](https://github.com/flancer32/teq-cms/issues/new) с описанием цели и ожидаемого поведения или [напишите мне](/ru/contacts). Приоритеты зависят от реальных задач; фиксированные сроки здесь я не обещаю.
