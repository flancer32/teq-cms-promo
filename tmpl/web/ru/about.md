# Я использую процесс, для которого создал TeqCMS

Я Алекс Гусев, автор TeqCMS. Этот двуязычный сайт — рабочий пример: я описываю результат, внешний ИИ-агент готовит файлы, а я проверяю, что публиковать.

## Чем занимается агент

Контент хранится в Markdown. У каждого языка свой исходник; общие шаблоны и CSS задают оформление. Агент может писать контент, готовить переводы, менять дизайн и навигацию. Я проверяю формулировки, изменения в Git и готовые страницы.

TeqCMS публикует подготовленные исходники. Она не запускает агента и не вызывает API языковой модели. Инструкции о проекте я храню в отдельном репозитории контекста; [ADSM](/ru/docs/adsm) объясняет этот подход.

## Посмотрите один материал в двух формах

Вы читаете HTML, сформированный из [Markdown этой страницы](/ru/about.md). Агенты находят публичные исходники через [llms.txt](/llms.txt); поисковики находят страницы для людей через [sitemap.xml](/sitemap.xml).

- [Код сайта](https://github.com/flancer32/teq-cms-promo): Markdown, шаблоны и стили.
- [Код CMS](https://github.com/flancer32/teq-cms): публикация и формирование страниц.
- [Другие рабочие сайты](/ru/examples): TeqFW и Wired Geese.
