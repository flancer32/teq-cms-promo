# TeqCMS — CMS для агентов

Агенты создают многоязычный Markdown в Git. TeqCMS отображает HTML для людей и может открывать выбранный Markdown другим агентам.

Стандартный CLI TeqFW запускает сайт и создаёт файлы обнаружения.
