# Работающие сайты. Открытые исходники.

Эти три приложения используют TeqCMS. Для каждого даю ссылку на сайт и репозиторий приложения, чтобы можно было изучить реализацию.

## TeqCMS

Сайт, который вы читаете: знакомство с продуктом, документация и связь с автором.

[Открыть сайт](https://cms.teqfw.com/) · [Исходники приложения](https://github.com/flancer32/teq-cms-promo)

## Wired Geese

Мой персональный сайт: информация о моей работе и способы связаться.

[Открыть сайт](https://wiredgeese.com/) · [Исходники приложения](https://github.com/flancer32/site_wg)

## TeqFW

Сайт проекта TeqFW: знакомство с фреймворком и его документацией.

[Открыть сайт](https://teqfw.com/) · [Исходники приложения](https://github.com/flancer32/site-teqfw)

## Проверьте на этом примере

Откройте [Markdown этой страницы](/ru/examples.md), переключите язык в шапке и сравните файлы локалей в репозитории сайта. Это части модели публикации, которые можно проверить самостоятельно.

[Создайте свой сайт](/ru/docs/install) или [обратитесь за помощью с внедрением](/ru/contacts).
