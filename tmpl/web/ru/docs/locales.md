# Локали и языки сайта

Агент поддерживает содержимое каждой локали в отдельном каталоге.

    TEQFW_TMPL__ALLOWED_LOCALES=en,ru
    TEQFW_TMPL__DEFAULT_LOCALE=en

Публикации размещаются в `tmpl/web/en/` и `tmpl/web/ru/`. HTML формируется из Markdown и шаблона представления.

Markdown доступен по URL без локали: выбирается английский источник, затем источник локали по умолчанию. HTML по URL с локалью требует соответствующего источника.
