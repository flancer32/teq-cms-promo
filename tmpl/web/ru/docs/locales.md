# Язык задаётся исходником

Для каждого поддерживаемого языка создайте Markdown-файл с одинаковым относительным путём. Например:

```text
tmpl/web/en/features.md
tmpl/web/ru/features.md
```

## Два представления

| URL | Представление |
| --- | --- |
| `/ru/features` | HTML из русского исходника |
| `/en/features` | HTML из английского исходника |
| `/features` | Исходный Markdown: сначала английский, затем локаль по умолчанию |

Нейтральный Markdown сначала выбирает исходник без локали в `tmpl/web/`. Если его нет, английский выбирается даже при русском языке по умолчанию. Если нет ни английского исходника, ни исходника локали по умолчанию, нейтральный ресурс возвращает 404. Другие языки не подставляются.

Для локализованного HTML нужны исходник именно запрошенного языка и доступный шаблон представления. Если русского файла нет, английская страница по русскому URL не появится. Локализованные URL с `.md` возвращают исходник указанного языка; адреса с `.html` показывают тот же HTML, что и адреса без расширения.

## Ссылки сохраняют язык

Внутренние HTML-ссылки должны содержать префикс локали. Переключатель использует доступные альтернативные HTML URL и сохраняет текущую страницу. Нейтральная Markdown-ссылка — отдельное представление, а не переключение языка.
