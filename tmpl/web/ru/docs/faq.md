# Что стоит узнать до внедрения

## Агент обязателен?

TeqCMS рассчитана на работу под управлением агента, но те же Markdown-файлы, шаблоны и CSS можно менять вручную. CMS отдаёт подготовленные файлы без работающего агента.

## CMS автоматически переводит страницы?

Нет. Языковые файлы ведут люди или внешние агенты. TeqCMS отображает подготовленный контент и не вызывает API перевода.

## Нужна база данных для контента?

Нет. Контент и шаблоны — файлы. Стандартное приложение работает на Node.js; страницы формируются на сервере, а не через сборку статического сайта.

## Агенты могут читать содержимое?

Да. Откройте [русский исходник этой страницы](/ru/docs/faq.md) с метаданными. Расширение `.md` явно запрашивает Markdown. Адреса без расширения выбирают HTML для человека либо Markdown для клиента, который его поддерживает; выбор языка также описан в [руководстве по URL](/ru/docs/locales).

## Что происходит при отсутствии перевода?

HTML URL конкретной локали возвращает 404, а другой язык незаметно не подставляется. HTML без префикса локали выбирает первый поддерживаемый язык по `Accept-Language`, затем язык по умолчанию. Нейтральный `.md` отдельно выбирает исходник без локали, затем английский, затем локаль по умолчанию.

## Есть визуальная админка?

TeqCMS её не предоставляет. Если редакторам нужен визуальный интерфейс, оцените их рабочий процесс до внедрения.

## Поддержка обязательна?

Нет. Движок открыт под Apache-2.0. [Моя помощь с внедрением](/ru/contacts) и [постоянная поддержка](/ru/subscription) — дополнительные услуги.

## Можно посмотреть реализацию?
