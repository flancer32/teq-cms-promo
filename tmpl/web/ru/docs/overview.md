# Сначала модель, затем практика

TeqCMS публикует Markdown из Git для агентов и формирует локализованный HTML для людей. Контент, переводы и оформление я храню в файлах; CMS обеспечивает публикацию.

## С чего начать

- [Установка](/ru/docs/install): запустить этот пример и изменить исходник.
- [Конфигурация](/ru/docs/config): настроить публикацию сайта и выбрать локали.
- [Локали](/ru/docs/locales): разобраться с HTML нужного языка и нейтральным Markdown.
- [Локализация](/ru/docs/translate): вести и проверять языковые версии.
- [CLI](/ru/docs/cli): запускать сайт и формировать файлы обнаружения.

## Работа над сайтом

- [Работа с агентами](/ru/docs/dev-llm): ставить задачи и проверять правки файлов.
- [ADSM](/ru/docs/adsm): организовать текстовые инструкции о проекте.
- [Интеграция](/ru/docs/plugins): понять границы приложения и пакетов.
- [Решение проблем](/ru/docs/troubleshooting) и [частые вопросы](/ru/docs/faq).

Подробный контракт движка описан в [руководстве по публикациям](https://github.com/flancer32/teq-cms/blob/main/docs/publications.md). Если нужна помощь с вашим проектом, [напишите мне](/ru/contacts).
