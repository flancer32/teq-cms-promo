# Дайте агенту задачу по сайту

TeqCMS рассчитана на работу с файлами, которые внешний ИИ-агент может менять напрямую. Агент редактирует Markdown, файлы локалей, шаблоны и CSS; я задаю направление и проверяю результат.

## Опишите результат

Укажите назначение страницы, аудиторию, источники фактов, языки и требования к стилю. Постоянные правила проекта храните в текстовых файлах, доступных агенту. Например:

> Добавь страницу продукта для разработчиков. Подготовь русский и английский Markdown, используй существующее оформление, добавь страницу в меню и покажи изменения в Git и готовый результат.

Можно также поручить адаптацию переводов, реорганизацию документации или изменение оформления сайта. Определите, какие файлы и действия входят в задачу.

## Проверьте перед публикацией

- Сверьте текст и утверждения о продукте с источниками.
- Посмотрите изменения в Git: контент, метаданные, переводы, шаблоны и CSS.
- Откройте страницы на компьютере и телефоне; проверьте ссылки и переключение языков.
- После изменений публикаций пересоберите `llms.txt` и `sitemap.xml`.
- Оставьте решение о публикации за владельцем сайта.

CMS отдаёт подготовленные файлы. Для чтения сайта не нужны работающий агент и API языковой модели; файлы можно менять и вручную.

[ADSM](/ru/docs/adsm) объясняет, как я организую инструкции о проекте. [Репозиторий этого сайта](https://github.com/flancer32/teq-cms-promo) показывает файлы и историю изменений.
