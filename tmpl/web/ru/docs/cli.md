# Две команды для двух задач

Стандартный CLI TeqFW запускает сайт и формирует файлы обнаружения. Команды выполняются из корня приложения.

## Запуск сайта

```sh
npm start
```

В этом репозитории скрипт вызывает `teq web:start`, а CLI загружает `.env` проекта. В другом приложении для `npx teq web:start` нужна его конфигурация.

## Обновление файлов обнаружения

После правок контента задайте ту же конфигурацию публикаций и локалей, что использует сервер, затем выполните:

```sh
npm run generate
```

Команда записывает `web/robots.txt`, `web/llms.txt` и `web/sitemap.xml`. Контент она не переводит.

- `llms.txt` перечисляет каждый доступный нейтральный Markdown-ресурс один раз.
- `sitemap.xml` перечисляет доступные локализованные HTML-публикации.
- `robots.txt` содержит правила обхода и ссылку на карту сайта.

Сервер и генератор загружают один `.env` — см. [конфигурацию](/ru/docs/config). Перед публикацией проверьте сгенерированные файлы вместе с контентом.
