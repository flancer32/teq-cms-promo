# Разделяйте контент и поведение приложения

Сайт отвечает за Markdown, общие шаблоны представления и статические ресурсы. TeqCMS подключается как пакет к Node.js-приложению и обеспечивает публикацию.

## Стандартный хост

CLI TeqFW отвечает за запуск процесса, загрузку конфигурации и жизненный цикл. Веб-пакет предоставляет `web:start` и конвейер запросов. TeqCMS регистрирует обработчики и предоставляет `cms:generate`. Пакет шаблонов отвечает за поиск с учётом локали и контракты рендеринга.

В этом сайте приложение выбирает Nunjucks. Другой хост может выбрать поддерживаемую реализацию, например Mustache, и предоставить совместимые шаблоны представления.

## Для контентной правки обычно не нужен плагин

Новая страница или языковая версия — Markdown-файл в `tmpl/web/{locale}/`. Изменение оформления относится к общим шаблонам. Новая интеграция во время работы приложения — отдельная инженерная задача.

Не стоит предполагать наличие каталога готовых интеграций. Перед расширением изучите [исходники движка и навык пакета](https://github.com/flancer32/teq-cms/tree/main/skills/teqfw-cms).
