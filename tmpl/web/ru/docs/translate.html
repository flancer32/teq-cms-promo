Локализация агентами

Агенты создают и редактируют содержимое каждой локали как файлы проекта. TeqCMS отображает подготовленный вариант и не обращается к API языковой модели.

  • Английские публикации: tmpl/web/en/{family}/
  • Русские публикации: tmpl/web/ru/{family}/
  • Изменения проходят проверку и фиксируются в Git.

После изменения публикаций обновите файлы обнаружения командой npx teq cms:generate.
