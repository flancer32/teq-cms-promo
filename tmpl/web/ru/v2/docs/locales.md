# Язык задаётся исходником

Для каждого поддерживаемого языка создайте Markdown-файл с одинаковым относительным путём. Например:

```text
tmpl/web/en/v2/features.md
tmpl/web/ru/v2/features.md
```

## Два представления

| URL | Представление |
| --- | --- |
| `/ru/v2/features` | HTML из русского исходника |
| `/en/v2/features` | HTML из английского исходника |
| `/v2/features` | Исходный Markdown: сначала английский, затем локаль по умолчанию |

Английский выбирается для нейтрального Markdown даже при русском языке по умолчанию. Если нет ни английского исходника, ни исходника локали по умолчанию, нейтральный ресурс возвращает 404. Другие языки не подставляются.

Для локализованного HTML нужны исходник именно запрошенного языка и доступный шаблон представления. Если русского файла нет, английская страница по русскому URL не появится. Локализованные URL с `.md` недоступны.

## Ссылки сохраняют язык

Внутренние HTML-ссылки должны содержать префикс локали. Переключатель использует доступные альтернативные HTML URL и сохраняет текущую страницу. Нейтральная Markdown-ссылка — отдельное представление, а не переключение языка.
