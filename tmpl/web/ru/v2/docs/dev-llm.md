# Поставьте задачу. Проверьте файлы.

Агент работает с теми же Markdown-файлами и шаблонами, которые можно редактировать вручную. Он находится вне CMS. Я поручаю ему подготовку правок, затем решаю, что публиковать.

## Опишите конкретный результат

Укажите назначение страницы, аудиторию, источники фактов, языки и ожидаемый результат. Например:

> Добавь страницу о трёх форматах моей помощи с TeqCMS: консультация, внедрение и постоянная поддержка. Пиши от моего имени в единственном числе. Используй существующие контакты и ссылки нужной локали.

## Что проверить

- Прочитайте текст и сверьте утверждения о продукте с документацией движка.
- Посмотрите разницу версий в Git, включая метаданные и языковые варианты.
- Откройте страницы на узком экране и проверьте переключение языка.
- Решение о публикации и других внешних действиях оставьте владельцу сайта.

Агент необязателен. Для выдачи подготовленных страниц не нужны работающий агент и подключение к API языковой модели.
