# CLI и автоматизация

TeqCMS использует стандартный CLI-хост TeqFW.

- `npx teq web:start` — запуск веб-сервера
- `npx teq cms:generate` — генерация `robots.txt`, `llms.txt` и `sitemap.xml`

Повторяйте генерацию после изменения публикаций и фиксируйте результат в Git.
