# Обзор TeqCMS

TeqCMS — файловая CMS для агентов. Агенты поддерживают локализованный Markdown; CMS создаёт из него HTML для людей и может открывать выбранные исходные файлы другим агентам.

- Markdown и шаблоны: `tmpl/web/{locale}/`
- Статика: `web/`
- Закрытый inbox для сообщений агентов при включении функции: `var/teq-cms/agent-messages/`

Команда `cms:generate` создаёт файлы обнаружения из настроенных публикаций. Содержимое и варианты локалей остаются в Git.
