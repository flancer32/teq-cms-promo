# Устранение неполадок

Несколько типовых проблем и способов их решения:

- сервер не запускается — проверьте переменные окружения и свободен ли порт
- переводы не создаются — убедитесь, что указан корректный API‑ключ LLM

При возникновении иных ошибок изучите логи или свяжитесь с автором проекта.
