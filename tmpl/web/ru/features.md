# Один источник для людей и агентов

TeqCMS — CMS для промосайтов, документации и многоязычных сайтов проектов, которые поддерживаются через файлы и Git. Я спроектировал её для работы с внешним ИИ-агентом.

## Один материал, разные представления

Markdown-файл страницы содержит текст и метаданные. Агент читает исходник; человек — HTML, который формируется из него через общие шаблоны. Отдельной версии текста для агента нет. У каждого языка свой поддерживаемый Markdown-файл, общий для двух представлений на этом языке.

Сравните [Markdown-исходник](/ru/features.md) этой страницы с её [HTML-представлением](/ru/features.html) или откройте [английскую HTML-страницу](/en/features.html).

## Два пути к контенту

- **Агенты:** [llms.txt](/llms.txt) перечисляет публичные материалы, по ссылкам на которые можно читать Markdown.
- **Люди:** [sitemap.xml](/sitemap.xml) помогает поисковикам обнаружить HTML-страницы; читатели приходят из поиска или через меню сайта.

Оба пути описывают один опубликованный контент. Эти файлы помогают обнаружению, но не гарантируют, что любой робот или агент воспользуется ими. [Выбор формата и языка](/ru/docs/locales) объясняет HTTP-поведение и ссылки с явным форматом.

## Агент может поддерживать весь сайт

Дайте агенту задачу и инструкции проекта. Он может менять:

- **Контент:** создавать и обновлять Markdown-страницы.
- **Языки:** переводить и адаптировать отдельные файлы локалей.
- **Оформление:** править CSS и общие шаблоны представления.
- **Структуру:** организовывать страницы, меню и ссылки.

Я проверяю изменения в Git и готовые страницы перед публикацией. Агент работает вне TeqCMS; CMS отдаёт подготовленные файлы без API языковой модели и работающего на сервере агента.

## Файлы под вашим контролем

Контент, переводы, шаблоны и CSS хранятся в Git. Можно проверить правку, вернуть версию или перенести исходники в другой проект. HTML формируется на сервере; для чтения не нужно приложение в браузере. Для публикации не требуются база контента и админка.

Этот процесс подходит техническим владельцам и небольшим командам, которым привычны Git и агент. Если авторам нужен визуальный редактор страниц, оцените это требование перед выбором TeqCMS.
